THE WIZARDING WORLD — ASSET CREDITS

This project currently uses original CSS artwork, inline SVG, Unicode ornamentation,
and curated local fallback data. No copyrighted film soundtrack or third-party character
photography is bundled.

Typography: the CSS stacks prefer Cinzel Decorative/Cinzel and Cormorant Garamond
when available locally, then use Palatino/Georgia/system serif fallbacks. No remote
font request is required.
